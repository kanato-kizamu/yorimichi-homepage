# よりみちホームページ

平成の個人ホームページ風の、小さな静的サイトです。技術のメモと雑談の部屋を用意した試作で、本文はサンプルです。個人のプロフィール・私的な会話・連絡先は含みません。

## ファイル

- `index.html`: HTML、CSS、JavaScript、オリジナル SVG をひとつにまとめたページ。
- `.nojekyll`: Jekyll の処理を使わず、そのまま配信するための目印。

## 見る・編集する

`index.html` をブラウザで開けます。依存パッケージやビルドは不要です。本文・見出し・配色は同じファイル内を編集してください。

GitHub Pages では Settings → Pages → Deploy from a branch を選び、`main` ブランチの `/ (root)` を公開元にします。

## 動作とプライバシー

- 320px 以上の画面を想定したレスポンシブレイアウト。
- メニューはページ内移動、「続きを読む」は標準 HTML の開閉操作です。
- 訪問カウンターは同じブラウザ内の `localStorage` にだけ保存されます。ページを開く／再読み込みするたびに増え、全訪問者の合計ではありません。
- 保存不可の環境でも本文は表示できます。JavaScript 無効時はカウンターとおみくじだけ動きません。
- アクセス解析、広告、外部フォント、外部画像、外部 JavaScript は使っていません。ホスティング側の通常のアクセス処理は別です。
- 掲示板や投稿フォームはありません。公開後の更新はソースを編集して行います。

個人の記録やプロフィールを追加するときは、公開してよい内容だけを載せてください。
